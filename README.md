# 케이원 | 상담 이력·매뉴얼 통합 관리 시스템

상담 이력 기록과 업무 매뉴얼 검색·열람을 한곳에서 지원하는 웹 서비스

> 개발 준비 단계 · 기능 및 일정은 기획안 기준

## 프로젝트 목표

- 상담 이력과 업무 매뉴얼 통합 관리
- 상담 중 필요한 자료 탐색 시간 단축
- 매뉴얼 개정 이력 관리 및 이전 버전 조회 지원
- 상담 이력과 참고 매뉴얼 연결

---

## 주요 기능

### 로그인 및 권한 관리

- 로그인 / 로그아웃
- 사용자 정보 및 역할별 접근 권한 관리

### 상담 이력

- 상담 목록 검색 및 조회
- 상담 이력 작성 / 수정 / 상세 조회

### 매뉴얼 검색 및 열람

- 업무 매뉴얼 검색
- 버전 선택 및 PDF 열람
- 이전 버전 조회

### 매뉴얼 등록 및 개정

- 매뉴얼 PDF 및 설명 등록
- 개정본 신규 버전 등록 및 기존 버전 보존

### 상담 이력과 매뉴얼 연결

- 참고 매뉴얼 선택 및 상담 이력에 연결
- 상담 상세 화면에서 연결된 매뉴얼 재열람

### 대시보드

- 주요 현황 시각화
- 최근 상담 이력 및 매뉴얼 조회
- 상담 이력 및 매뉴얼 메뉴 이동

---

## 주요 사용 흐름

1. 로그인 후 상담 이력 작성 또는 기존 이력 조회
2. 업무 매뉴얼 검색 및 버전 선택
3. 매뉴얼 PDF 열람 및 참고 매뉴얼 연결
4. 상담 상세 화면에서 상담 내용 확인 및 참고 매뉴얼 재열람
